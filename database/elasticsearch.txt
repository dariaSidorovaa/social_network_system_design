1. Elasticsearch используется как поисковый индекс для обеспечения поиска локаций по названию.

2. Хранимые данные и структура индексов:
В Elasticsearch хранятся денормализованные документы, достаточные для поиска и ранжирования результатов без выполнения JOIN.
Индексы: locations_index - документы локаций для поиска/подсказок
Поля:
  2.1 locations.id
  2.2 locations.name

3. Интеграция с Postgresql:
  3.1 Cинхронизация выполняется на стороне backend-приложения при успешном изменении сущности в Postgresql;
  3.2 Elasticsearch работает в модели согласованности eventual consistency: обновления в индексе могут происходить с небольшой задержкой относительно Postgresql -> допустимы кратковременные расхождения в результатах поиска.
  3.3 При ошибке обновления Elasticsearch операция в Postgresql не откатывается, ошибка логируется, допускается повторная синхронизация.
